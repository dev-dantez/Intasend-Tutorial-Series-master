# Quick Start: Identity Package Download

## For Users

### Step 1: Upgrade to Premium
1. Go to "Mock Platform" page
2. Click "Try PRO" button
3. Complete payment (500 KES)
4. Premium activated ✅

### Step 2: Generate Identity
1. Select gender (Male/Female/Any)
2. Select country (Kenya/USA/UK/Any)
3. Enter age (optional, 18-80)
4. Check "Include CV" for professional profile
5. Click "Generate New Identity"

### Step 3: Download Package
1. Click "Download Complete Package (ZIP)"
2. ZIP file downloads automatically
3. Extract and use files

## What You Get

### In the ZIP File:
```
Identity_Package_[Name]_[Date].zip
├── IDENTITY_DETAILS.txt      (Complete profile)
├── identity_data.json         (Data export)
├── profile_photo.svg          (Avatar image)
├── CV_[Name].pdf             (Resume - if CV included)
└── README.txt                (Documentation)
```

### File Sizes:
- Without CV: ~50 KB
- With CV: ~150 KB

## Common Questions

**Q: Can I download without Premium?**
A: No, Premium subscription required for downloads.

**Q: What if I don't check "Include CV"?**
A: Package still includes all other files, just no CV PDF.

**Q: Can I download multiple times?**
A: Yes, generate new identities and download as many as needed.

**Q: What format is the profile image?**
A: SVG (Scalable Vector Graphics) - works everywhere.

**Q: Is the data real?**
A: No, all data is randomly generated for testing purposes.

**Q: Can I edit the files?**
A: Yes, all files are standard formats you can open and edit.

### README.txt

- Use for: Package information
- Format: Plain text

## Troubleshooting

### Download doesn't start?
- Check you're logged in
- Verify Premium is active
- Try refreshing the page

### ZIP file is empty?
- Ensure identity was generated
- Check browser download settings
- Try different browser

### Missing CV in package?
- Make sure "Include CV" was checked
- Regenerate with CV option enabled

### Can't open files?
- TXT/JSON: Use any text editor
- SVG: Use browser or image viewer
- PDF: Use PDF reader
